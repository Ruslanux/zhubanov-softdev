Education DevTools In production

Interactive platform for learning programming

Test-first Ruby learning: students write code in the browser, it runs in an isolated sandbox and is checked by automated tests.

61exercises across 16 lessons
266platform tests
2interface languages

01Challenge

Programming is best learned by practice, but reviewing solutions by hand is expensive and running other people's code on a server is unsafe.

02Solution

  • A code editor with syntax highlighting right in the browser
  • An isolated sandbox with time and memory limits; a Docker container mode
  • Solutions are checked by automated tests with instant feedback
  • Gamification: points, levels, achievements, streaks and a leaderboard
  • Hints and solutions with a point penalty, attempt history
  • A JWT-authenticated JSON API for mobile clients and an admin panel

03Results

  • The platform is in production
  • A 4-module curriculum from the basics to the newest language features
  • Interface in Russian and English
