  тіркеледі.
- **Мессенджерлерден** (Telegram, WhatsApp) — егер сіз бізге сол жерге жазсаңыз: аты немесе ник, телефон

- **Техникалық деректер.** Сайт GitHub Pages-те орналастырылған: GitHub қауіпсіздік мақсатында
  келушілердің IP-мекенжайларын жазады. Қаріптер Google Fonts серверлерінен жүктеледі, сондықтан Google
  сіздің IP-мекенжайыңызды алады. Бриф жіберілгенде Cloudflare спамнан қорғау үшін (жіберу санын шектейді)
  IP-мекенжайыңызды пайдаланады; біз оны алмаймыз және сақтамаймыз. Сайттың өзі **cookie мен аналитика
